อ่านภาพนี้อย่างไร

  1. Browser เรียก Next.js ที่ port 3000 แล้ว API proxy ส่งต่อเข้า FastAPI บน Docker network
  2. FastAPI รับอัปโหลด อ่านข้อความหรือ OCR แบ่ง chunks และสร้าง embeddings ก่อนแทนที่เอกสารเดิมใน PostgreSQL แบบ atomic ไม่เก็บไฟล์ต้นฉบับไว้
  3. เมื่อถามคำถาม Backend สร้าง query embedding ค้น pgvector แล้วส่งหลักฐานให้ LLM ก่อนตรวจ JSON และ citation IDs การผ่าน validation ไม่รับประกันว่าคำตอบถูกต้อง
  4. Native mode ใช้ Ollama บน Mac ผ่าน GPU ส่วน portable mode ใช้ Ollama container ผ่าน CPU จึงแสดงเป็นทางเลือก ไม่ใช่ต้องเปิดทั้งคู่
  5. Evaluation เป็น CLI แยก ใช้ข้อมูลสมมติและ cosine search ใน memory เรียก Ollama แล้วเขียนรายงาน JSON ไม่ได้ทดสอบ API, pgvector หรือ OCR

การเชื่อมต่อใช้ HTTP ภายในเครื่อง ไม่ใช่ AWS/serverless deployment ไม่มีระบบผู้ใช้ หลังบ้าน หรือ background worker ในเวอร์ชันนี้ พอร์ต host ที่แสดงเป็นค่าเริ่มต้นและแก้ได้ผ่าน environment
