# Thai OCR validation — 2026-11-09

## Scope

Real Poppler/Tesseract processing of `samples/ocr/thai-policy-scan.pdf`, a clean synthetic image-only
Thai/English policy fixture. This is not a representative evaluation of real photographed/scanned documents.
The original PDF has no extractable text, so this checks actual OCR rather than PDF text extraction.

## Observed result

- Tesseract: 5.5.0, Thai + English language packs, automatic page segmentation (PSM 3).
- Rendering: PNG, maximum side 2000 pixels.
- Correctly retained Thai policy phrases, receipt requirement, and THB 500 daily limit.
- Page number: 1; extraction method: `ocr`, retained through the upload API and PostgreSQL retrieval.
- Unicode NFC normalization and removal of whitespace: 106 reference characters, 3 character edits.
- Character error rate: **2.83%**. Stray characters `v`, `๕`, `&` appeared on an extra line.
- Raw expected and actual outputs: `ocr-thai-2026-11-09.json`.

The observed stray characters are not silently filtered from user documents. Global segmentation settings
were not changed to fit one example; doing so could harm other layouts. Review cited source text when using
OCR output. Complex layouts, skew, handwriting, low contrast and low resolution remain unvalidated.

## Checks

All **104 tests passed inside the backend image**, with real OCR and PostgreSQL enabled. Model calls are
mocked in these tests. PostgreSQL tests use isolated schemas and do not replace the user's documents.
Coverage includes mixed PDF pages, Thai/English scans, provenance, empty scans, invalid PDFs, OCR failures,
page limits and budget checks, and rollback/preservation of the prior document after failed ingestion.

From the repository root:

```bash
docker compose up -d --wait postgres
docker compose build backend
docker compose run --rm --no-deps -T -e RUN_OCR_TESTS=1 -e RUN_POSTGRES_TESTS=1 -e PYTHONPATH=backend -v "$(pwd):/workspace:ro" -w /workspace backend python -m unittest discover -s backend/tests -p 'test_*.py' -q
```

The 120-second document OCR budget is checked before starting an OCR page; it is not a hard deadline.
An already-running page can take another 30 seconds to render and 30 seconds to recognize.
